# Changelog

## 0.3.5 — 2026-11-09

**Первый публичный выпуск `@apilki/wb`.** Клиент Wildberries API для JavaScript и TypeScript: 22 подклиента по 12 разделам API, 304 операции.

### Добавлено
- Подклиенты по разделам: общее, товары и цены, заказы FBS/DBW/DBS, самовывоз, FBW, продвижение, коммуникации и отзывы, аналитика, отчёты, финансы и документы.
- Типы TypeScript для всех операций и моделей; сборки CommonJS (`dist/`) и ESM (`dist/esm/`).
- Ядро `core`: проверка токена (тип, категории, read-only) до сетевого вызова, ограничитель частоты по заголовкам `X-Ratelimit-*` с одним повтором после 429, единый разбор двух конвертов ошибок вендора.
